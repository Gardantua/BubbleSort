# Ball Sort Puzzle

Tarayıcıda çalışan küçük bir top sıralama oyunu. Aynı renk topları tüplerde bir araya getirme fikri üzerinden JavaScript ile oyun durumu ve tıklama etkileşimlerini çalıştım.

HTML, CSS ve JavaScript tek bir [index.html](index.html) dosyasında. Dosyayı tarayıcıda açmak yeterli; paket kurulumu veya backend gerekmiyor.

Repo adı `BubbleSort`, ama içerik sıralama algoritması uygulaması değil, Ball Sort türünde bir oyun denemesi.
